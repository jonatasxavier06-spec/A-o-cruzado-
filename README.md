# Site Aço Cruzado — Estruturas Metálicas

Site institucional em arquivo único (`index.html`), sem build, sem dependências externas além das fontes do Google Fonts via CDN. Todas as imagens estão embutidas no próprio arquivo.

## Publicar na Vercel

1. Suba este repositório no GitHub (veja o passo a passo enviado no chat).
2. Em vercel.com, importe o repositório.
3. Framework Preset: "Other" — não é preciso comando de build nem pasta de saída.
4. Deploy.

Qualquer novo `git push` na branch principal atualiza o site automaticamente.
